# 수학 탐구실 (5학년)

학생이 직접 조작하며 개념을 발견하고, 기본 → 심화 → 서술형까지 해결하는 수학 웹앱입니다.

## 폴더 구조
- `index.html` : 단원 선택 첫 화면 (단원 목록은 이 파일의 `UNITS`에서 관리)
- `config.js` : 엄마 설정 (구글 시트 주소, 입장 비밀번호, 아이 이름)
- `assets/` : 모든 단원이 함께 쓰는 디자인(`style.css`)과 기능(`core.js`: 문제 채점, 학생 로그인, 시트 기록)
- `u2/` : 5-1 2단원 약수와 배수 (서윤)
- `br300/` : 영어 Bricks Reading 300 Level 1 (서윤) — 본문은 넣지 않음(책으로 읽기), 단어·이해 확인·생각 쓰기·단어 놀이
- `en2/` : 영어 Smart Phonics 2 (Unit 1~8 + Sound Expansion 1~4), 영어 소리는 기기 TTS
- `g1u4/`, `g1u6/` : 1-2 4단원 덧셈과 뺄셈(2), 6단원 덧셈과 뺄셈(3) (서현) — 1학년용 공통 키트 `assets/g1kit.js`, `assets/g1.css`
- `u3/`, `u4/` … : 이후 단원을 같은 방식으로 추가
- `apps-script/Code.gs` : 구글 시트에 붙여 넣는 기록 수집 코드

## 학습 기록 받기 (구글 시트)
1. 구글 시트 `수학 탐구실 학습 기록` 열기 → 확장 프로그램 → Apps Script
2. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs`를 붙여 넣고 저장
3. 배포 → 새 배포 → 유형 '웹 앱' → 실행: 나 / 액세스 권한: **모든 사용자** → 배포 → 권한 허용
4. 나온 웹 앱 URL을 `config.js`의 `sheetUrl`에 넣기

시트에는 `기록`, `아이별 현황`, `마음 우체통`(기분·편지·질문) 탭이 자동으로 생깁니다.
